# Personalización del sitio  Joan Fandos

* **Tema activo:** Astra (última versión disponible).
* **Por qué lo elegí:** Ligero, actualizado frecuentemente, muy buena valoración en el repositorio oficial y totalmente compatible con PHP 8.3 y el editor de bloques.
* **Plugin instalado:** Contact Form 7 (última versión, mantenimiento activo, +10 millones de instalaciones activas).
* **Por qué lo necesito:** Permite gestionar formularios de contacto sin modificar el núcleo de WordPress y cumple criterios de seguridad y soporte activo.
* **Límites de PHP configurados (`config/uploads.ini`):** `upload_max_filesize = 64M`, `post_max_size = 64M`, `memory_limit = 256M`.
* **Estructura de contenidos:**
  * **Páginas:** Inicio (portada estática), Sobre el proyecto (con subpágina Tecnologías) y Contacto.
  * **Categorías:** Novedades y Tutoriales (3 entradas publicadas).
  * **Menú principal:** Inicio | Sobre el proyecto ( Tecnologías) | Contacto.
